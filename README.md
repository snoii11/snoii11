### 🤖 featured project — kiooo

<p align="center">
  <a href="https://github.com/snoii11/kiooo">
    <img src="https://github-readme-stats.vercel.app/api/pin/?username=snoii11&repo=kiooo&theme=tokyonight&hide_border=true&border_radius=10" alt="kiooo repo card" />

> **kiooo** — a powerful moderation-focused Discord bot built with Python 🛡️
> 60+ slash commands across 8 cogs, backed by MongoDB and hosted 24/7.

| Cog | What it does |
| --- | --- |
| 🛡️ `antinuke` | raid protection — action thresholds, auto-punish (kick / ban / strip roles), server lockdown |
| 🔨 `moderation` | kick, ban, unban, timeout, warns, purge, channel lock — with confirm buttons |
| 💰 `economy` | work, mine, fish & farm for KKD — shop, inventory, tools, daily rewards, leaderboards |
| 🧰 `utility` | help menu, userinfo, serverinfo, avatars, banners, polls, ping |
| 🎭 `fun` | memes, trivia, 8ball, rock-paper-scissors, roasts, translator, dice & more |
| 📜 `logger` | full audit logging — messages, members, voice, channels, roles, commands, errors |
| 👑 `owner` | eval, global bans, blacklists, no-prefix access, multi-server management |
| ⭐ `premium` | premium key system — grant, check, revoke, stats |
